# Assets

Brand artwork for demo-agent. Paths below are relative to this directory.

| Use | File |
| --- | --- |
| README or presentation banner | [`brand/original-banner.png`](brand/original-banner.png) |
| Original dark app icon | [`brand/original-icon-dark.png`](brand/original-icon-dark.png) |
| Mark on a light background | [`brand/mark-dark.svg`](brand/mark-dark.svg) |
| Mark on a dark background | [`brand/mark-light.svg`](brand/mark-light.svg) |
| Vector app icons | [`brand/icon-dark.svg`](brand/icon-dark.svg) / [`brand/icon-light.svg`](brand/icon-light.svg) |
| Horizontal wordmarks | [`brand/lockup-dark.svg`](brand/lockup-dark.svg) / [`brand/lockup-light.svg`](brand/lockup-light.svg) |
| Browser favicon | [`brand/favicon.svg`](brand/favicon.svg) |
| Original-to-vector comparison | [`brand/preview.html`](brand/preview.html) |

The PNG artwork is preserved unchanged. SVGs are hand-traced interpretations of the original dark icon, with simplified shading. All marks retain three cards; legibility of the layer gaps is limited at 16 px. Wordmarks contain live text with font fallbacks, rather than outlined lettering.

Use the original banner for large editorial surfaces and the SVG marks for transparent placement. Preserve aspect ratios. See [`brand/README.md`](brand/README.md) for detailed notes.
